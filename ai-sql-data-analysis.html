AI & DATA ANALYSIS

AI can write SQL.
Analysts still need to think.

The query is not the starting point. Good analysis starts with planning, defining the desired output, then writing, testing and validating the SQL.

Monika Verma22 September 20264 min read

01 · PLANNING

Start with the question, not the SQL.

Before asking AI to write code, define the problem in plain language. The analyst should know what decision the analysis needs to support.

Business question Data grain Source tables Metrics Filters Edge cases
If you cannot explain the logic clearly without SQL, AI is being asked to guess the analysis.
02 · DESIRED OUTPUT

Know what the answer should look like.

Defining the output before writing the query makes testing easier. For example: monthly revenue by marketing channel for completed orders only.

MonthChannelRevenue
Jan 2026Google Ads15,000
Jan 2026Social Media9,500
Jan 2026SEO11,200
If you do not know the expected shape of the answer, it is much harder to know whether the query is correct.
03 · QUERY

Now let AI help write the SQL.

Once the logic and output are clear, AI becomes useful as a drafting partner. It can generate syntax, explain joins, suggest functions and speed up iteration.

SELECT
    DATE_TRUNC('month', order_date) AS month,
    marketing_channel,
    SUM(revenue) AS total_revenue
FROM orders
WHERE order_status = 'completed'
  AND order_date >= '2026-01-01'
GROUP BY 1, 2
ORDER BY 1, 3 DESC;
The query can be simple. The thinking behind the query is the valuable part.
04 · TEST

A query can run successfully and still be wrong.

Testing is where analysts protect the quality of the result. Do not treat the first AI-generated query as final.

RowsDid the row count change unexpectedly? JoinsDid a join duplicate records? NullsAre missing values being dropped? TotalsDo totals match a trusted source?
05 · VALIDATE

SQL gives the number. Analysis gives the meaning.

If one channel is down 25%, the job is not finished. The analyst still needs to ask why and whether the result makes sense in context.

Was traffic lower? Did conversion drop? Was tracking broken? Did campaign mix change? Is seasonality involved?
Understanding the output is now more valuable because AI is making the code itself easier to produce.

THE TAKEAWAY

Let AI accelerate the code — not replace the analysis.

HumanPlanning HumanDesired output AI + HumanSQL query HumanTesting HumanValidation & insight

AI is a powerful assistant for SQL. But trustworthy analysis still depends on the analyst owning the logic, the checks and the interpretation.
